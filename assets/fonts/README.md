Portfolio text uses `typography.css`, shared by all portfolio pages:

- `SF-Pro-Display-Regular.woff2` — SF Pro Display, regular weight (400).
- `SF-Pro-Display-Medium.woff2` — SF Pro Display, medium weight (500).
- `SF-Pro-Display-Semibold.woff2` — SF Pro Display, semibold weight (600) for the impact figures.

These WOFF2 files were converted from the user's installed `/Library/Fonts/SF-Pro-Display-Regular.otf`, `/Library/Fonts/SF-Pro-Display-Medium.otf`, and `/Library/Fonts/SF-Pro-Display-Semibold.otf` files, as requested for this case study. They retain the source font names and weights and are subset to Latin, extended Latin, punctuation, currency, letterlike symbols, arrows and geometric shapes used by the page.

`Garrigos-Ornamentos.woff2` supplies the decorative ornament glyph in `styles.css`.
Product demos keep their original fonts: the verification demos use their vendored Inter, and the One breath explorer uses `FolioBkBT-Book.ttf`. The older Folio Bold and IBM Plex Mono assets remain available but are no longer loaded by the portfolio interface.
